Banister's Fitness–Fatigue model treats each training dose as an impulse that raises both a slow-decaying "fitness" component and a fast-decaying "fatigue" component. Performance is modeled as fitness minus fatigue. After a hard block, fatigue is high and predicted performance dips; as fatigue fades faster than fitness, the model predicts a rebound — the familiar taper effect.

AthleteIQ uses a simplified discrete form of that impulse-response idea: fitness decays with a long time constant (about 42 days) and fatigue with a short one (about 7 days). The resulting performance index is an independent read of the same session-RPE series used for ACWR. It is not a VO2 or race-time forecast; it is a signed index of whether recent load is leaving the athlete more accumulated than recovered.

Because fatigue decays on a short horizon, several days with little or no new load can improve the index even without a new check-in quality jump. That is why a nightly recalculation can change the performance read as calendar time passes. Like ACWR, this is a model, not a lab test — coaches should weigh it next to sleep, HRV, and how the athlete actually looks in training.
